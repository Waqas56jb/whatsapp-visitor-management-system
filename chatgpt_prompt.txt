6. SLOT CONTRACT (SOURCE OF TRUTH — PUT THIS IN THE PROMPT YOU RETURN)
==================================================

slots = {
  name,        // string, visitor full name
  company,     // string
  purpose,     // string
  hostName,    // string from directory only
  hostId,      // number from directory only
  hostDept,    // string from directory
  date,        // YYYY-MM-DD
  time         // HH:mm 24h
}

merge rule:
  incoming empty NEVER overwrites existing
  LLM guess NEVER overwrites existing
  only visitor text or a numbered host pick may write a slot

ask order:
  name → company → purpose → host → date → time → confirm → book

greeting-only (hi, hello, hey, dumela, good morning, …) AND no slots:
  send official welcome ONCE, set welcomed=true

greeting-only AND slots already have data:
  do not welcome again; remind the next missing field or the confirmation

new booking / another booking / start over:
  wipe slots, keep language, send official welcome

isConfirm (yes, yebo, ke a dumela, …) AND all slots ready:
  book, then wipe slots, keep lastRef

host matching:
  compare against directory names and departments only
  ignore stopwords: visit, date, is, on, at, purpose, company, from
  "date is", "visit", "on 25" are NOT hosts
